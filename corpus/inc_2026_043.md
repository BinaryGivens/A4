# INC-2026-043

**Opened:** 2026-02-24 14:07 UTC
**Closed:** 2026-03-02 09:30 UTC
**Severity:** High
**Reporting analyst:** Sofia Brandt (Tier 2)

## Summary

The EDR platform raised a credential-dumping alert on VAN-WKS-2210. A process running as
the interactive user opened a handle to the LSASS process with read access and wrote a
dump file to `C:\Users\Public\lsass_2210.tmp`. The dump file was collected and deleted
within eleven minutes.

## Affected hosts

- **VAN-WKS-2210** - engineering workstation. Alert raised at 14:03 UTC.

## Techniques observed

- T1003.001 OS Credential Dumping: LSASS Memory.
- T1105 Ingress Tool Transfer - the dumping utility was downloaded before execution.
- T1547.001 Boot or Logon Autostart Execution: Registry Run Keys / Startup Folder - a run
  key was written to survive reboot.

## Indicators

- Dropped file `svcmon.exe`, SHA-256
  `3b1f7c9a4e0d2a6b8f5c1d3e7a9b0c2d4e6f8a1b3c5d7e9f0a2b4c6d8e0f1a35`.
- Registry value `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\SvcMon`.

## Analyst notes

The dumping utility arrived over the temporary 22/tcp path from SEG-CORP into SEG-ENG. That
path exists because of the firewall exception on VAN-SRV-BLD02 recorded in the asset
inventory. The subsequent handling of that exception is recorded in the change management
log, not here; this ticket closed before it was resolved.

Sofia Brandt requested a forensic hold on VAN-WKS-2210. The hold is the reason the change
advisory board deferred identity changes in early March.

## How the tool arrived

The EDR platform recorded `svcmon.exe` being written by an SSH session process. The session
originated from an address in SEG-CORP and reached VAN-WKS-2210 over 22/tcp. That path is
permitted because of the temporary firewall exception described in the asset inventory,
which allows 22/tcp and 8080/tcp from SEG-CORP into SEG-ENG. Without that exception the
transfer would have been dropped at the segment boundary.

Sofia Brandt raised the segment exception as a contributing factor and referred it to change
management for removal.

## Containment and remediation

VAN-WKS-2210 was isolated at 14:31 UTC on 2026-02-24, imaged on 2026-02-25 and re-imaged on
2026-03-01. The run key was removed as part of the re-image. The interactive user's account
was reset with a forced re-enrolment, unlike the handling in INC-2026-041.

A forensic hold was placed on the image and on the host's EDR telemetry. The hold remained
in force through March and is one of the two holds that led the change advisory board to
freeze non-emergency identity changes.

## What was not established

The dump file was deleted before it could be collected, so it is not known which credentials
were recovered from it. The engineering workstation's interactive user held no privileged
group membership beyond GRP-ENG-BUILD, which bounds but does not eliminate the exposure.

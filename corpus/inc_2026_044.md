# INC-2026-044

**Opened:** 2026-03-01 06:55 UTC
**Closed:** 2026-03-13 17:45 UTC
**Severity:** High
**Reporting analyst:** Kenji Watanabe (Tier 1)

## Summary

Proxy telemetry showed a regular outbound HTTPS pattern from VAN-WKS-2210 to the address
198.51.100.77, resolving from the hostname `cdn-metrics-eu.example.net`. Requests occurred
every 293 seconds with a small jitter and carried a constant User-Agent string. The pattern
is consistent with command-and-control beaconing over web protocols.

## Affected hosts

- **VAN-WKS-2210** - source of the beaconing. Same host as INC-2026-043.

## Techniques observed

- T1071.001 Application Layer Protocol: Web Protocols.
- T1053.005 Scheduled Task/Job: Scheduled Task - a scheduled task named `MetricsUpload`
  re-launched the beacon after reboot.

## Indicators

- Destination address 198.51.100.77.
- Destination hostname `cdn-metrics-eu.example.net`.
- Beacon interval 293 seconds.

## Analyst notes

The beaconing destination 198.51.100.77 was blocked at the perimeter on 2026-03-11 under
CHG-2026-0893. Beaconing stopped immediately after the block.

Attribution of 198.51.100.77 is not made in this ticket. The address was passed to the
threat intelligence function for enrichment and the resulting assessment is held in the
threat intelligence report, not here.

## Beacon characteristics

The interval is 293 seconds with a jitter of plus or minus seven percent. Each request is an
HTTPS POST of between 800 and 1,400 bytes with a response under 400 bytes, except for four
occasions on which the response exceeded 60 KB. Those four responses are assessed as tasking
or tool delivery. The retained proxy data does not contain response bodies, so the content is
unknown.

The scheduled task `MetricsUpload` re-launched the beacon process after each of the two
reboots recorded on VAN-WKS-2210 during the window. The task was created under the
interactive user's context and was removed when the host was re-imaged.

## Relationship to other tickets

VAN-WKS-2210 is the same host as INC-2026-043. The beacon binary and the credential dumping
tool are the same file. The SOC treated the two tickets separately because the detections
came from different platforms and the link was only made on 2026-03-02 when the malware
analysis was returned.

## Deliberate omission

This ticket records the destination address and the observed behaviour. It does not name an
actor. Vandelay's SOC procedure separates observation from attribution: attribution is made
by the threat intelligence function and recorded in intelligence products, not in incident
tickets. An analyst who wants the attribution for 198.51.100.77 must go to the intelligence
holdings.
